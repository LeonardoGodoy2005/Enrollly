# Enrollly — Formulário de Matrícula

Uma interface de matrícula escolar desenvolvida com **HTML5, CSS3 e JavaScript**, com foco em responsividade, acessibilidade e validação de formulários.

## ✨ Funcionalidades

- Formulário de matrícula com dados pessoais e informações acadêmicas.
- Campos para nome completo, data de nascimento, telefone e e-mail.
- Seleção de curso e turno.
- Campo de observações.
- Máscara automática para formatação do telefone.
- Validação de nome, telefone e data de nascimento.
- Mensagens de feedback para erros e validações concluídas.
- Layout responsivo para computadores, tablets e celulares.
- Estados visuais para foco e interação com os campos.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Flexbox e CSS Grid
- Media Queries
- Git e GitHub

## ⚠️ Observação

Este projeto é um protótipo front-end. As validações e mensagens de feedback funcionam no navegador, mas os dados preenchidos não são enviados nem armazenados em um servidor.
